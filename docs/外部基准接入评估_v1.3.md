# 外部基准接入评估（QB-v1.3 pilot）

## 结论

外部 benchmark 不再只作为“换数字改写”的模板来源。本轮将它们分为两条轨道：

- `public_calibration`：允许直接使用公开题，用于校准难度、评分器和模型横向对比；标记为 `pilot`，默认不进入日常 run。
- `private_longitudinal`：用于持续漂移结论；必须是未公开、非参数替换、程序化可评分的独立题。

公开题的得分可以作为 calibration signal，但不得与私有漂移探针合并成同一统计量。

## 已落地

| 来源 | 本地快照 | 标准化 | 可运行 pilot | 处理 |
|---|---|---|---|---|
| GPQA Diamond | `raw_sources/simple-evals/gpqa_diamond.csv` | `normalized/gpqa_diamond_candidates.jsonl` | 30 题，`A5-GPQA-*` | 直接校准轨，固定选项顺序，EM 评分 |
| Simple-evals | `raw_sources/simple-evals/` Git 快照 | 提取器已支持 | 待完整数据 | SimpleQA 官方依赖语义 grader，别名复核前不直接上线 |
| MATH / MATH-500 | `raw_sources/math/` Git 快照 | 提取器已支持 MATH-500 CSV | 待符号等价评分器 | 不用字符串 EM 冒充数学等价 |
| GSM8K | `raw_sources/grade-school-math/` Git 快照 + 已有 parquet | 已有 7,473 条 | 不新增直接 pilot | 顶级模型过度饱和，仅作方法库 |
| SuperGPQA | 未完成（Hugging Face 与镜像均超时） | 提取器已支持官方 JSONL | 待许可归因抽样 | ODC-BY 复合数据，需同时遵守引用数据集许可 |

## 来源筛选矩阵

| 题库 | 当前结论 | 原因 |
|---|---|---|
| LiveCodeBench v5 | 接入，但不拉取 4GB+ 全量仓库 | 已有官方 runner 和 test-generation 快照；code-generation v5 应按时间、难度和无图片条件增量抽取 |
| Aider Polyglot | 不复制榜单题 | 它是多语言仓库编辑评测，需独立 repo patch 执行器 |
| SWE-bench Verified | 待执行层升级 | 需 Docker/仓库镜像/测试补丁，不能降级为单轮文本题 |
| HumanEval | 不直接纳入 | 饱和与污染风险高；仅保留隐藏测试方法 |
| HLE | 待授权 | 官方数据集为 gated，且包含图像题；未经接受条款不复制内容 |
| SimpleQA | 条件接入 | 短答事实性有价值，但官方使用 LLM grader；需别名集或冻结 grader |
| GPQA / Diamond | 已接入 | 纯文本、固定选项、程序化 EM；明确标记公开污染风险 |
| SuperGPQA | 条件接入 | 覆盖面广且可 EM，但是复合许可和公开污染风险需单独记录 |
| AIME / MATH | 条件接入 | 需符号等价而非简单 EM；应按难度 pilot 后选取 30–85% 通过率题 |
| GSM8K | 不用于高难主轨 | 饱和、污染高，不能通过“换数字”变成新题 |
| MathVista / MMMU / ChartQA / DocVQA | 待多模态升级 | 需图像字段、媒体存储、Provider 图片消息和多模态评分；禁止丢图转文本 |
| MRCR / DROP | 可下一批接入 | 纯文本、可 EM/F1；需控制上下文长度和 Provider 成本 |
| Global MMLU Lite / MMLU-Pro | 保留校准轨 | MMLU-Pro 已有完整候选层；多语言应分语言层化，不与英文总分直接混合 |
| MTOB | 待任务定义复核 | 先确认所指版本和可执行评分协议 |
| GAIA | 待 agent runner | 需浏览、文件、代码执行与外部工具；不应当作闭卷问答 |
| AgentBench | 待环境容器 | 需交互式环境、事务状态和轨迹评分 |

## 新质量门禁

`scripts/audit_bank_quality.py` 检查原文重复、屏蔽数字后的参数替换模板，以及同模块高相似题对与聚类。

当前 QB-v1.2 的报告保存在 `manifests/qbv1_2_near_duplicate_audit.json`。上一版“exact template duplicate = 0”不再作为充分验收条件。

本轮先按“每个重复簇保留一题”定位出 170 道待替换题，决策记录在 `manifests/qbv1_2_near_duplicate_retirements.json`。随后已用 170 道不同任务结构完成替换，正式 QB-v1.3 主轨恢复为 627 道 `ready` 题，新审计为 0 个近重复对。QB-v1.2 历史快照保持不变。
